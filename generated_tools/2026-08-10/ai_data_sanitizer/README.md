# AI Data Sanitizer
This tool sanitizes AI training data to prevent data leakage and ensure model fairness.

## Installation
To install the required packages, run:
```bash
pip install pandas numpy scikit-learn
```

## Usage
To use the AI Data Sanitizer, run:
```bash
python ai_data_sanitizer.py --input-path input.csv --output-path output.csv
```
Replace `input.csv` with the path to your training data file and `output.csv` with the desired path for the sanitized data file.
