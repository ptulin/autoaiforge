# Explainability Dashboard
This tool provides a web-based dashboard for visualizing and explaining the decisions made by AI models in human-AI collaborative systems.

## Features
* Model interpretability
* Feature importance
* Decision boundary visualization

## Requirements
* Python 3.8+
* Dash
* Dash Core Components
* Dash HTML Components
* Plotly
* Pandas
* Scikit-learn

## Usage
1. Install the required packages: `pip install -r requirements.txt`
2. Run the dashboard: `python explainability_dashboard.py --model model.pkl --dataset dataset.csv`
